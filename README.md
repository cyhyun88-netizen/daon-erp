# 다온종합건설 사내 ERP

사내 업무포탈 (전자결재 · 문서관리 · 공사관리 · 업무관리 · 급여조회 등).

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 프론트엔드 (현재 단일 파일 프로토타입) |
| `db/schema.sql` | PostgreSQL 스키마 (조직 · 권한 · 전자결재 · 급여 · 현장 · 업무관리 · 문서관리) |
| `db/seed.sql` | 초기 데이터 |
| `db/queries.sql` | 주요 조회 쿼리 |
| `fonts/`, `img/` | 글꼴 · 로고 · 직인 · 서명 이미지 |

## 진행 계획

1. Supabase (DB · Auth · Storage) 스키마 이전
2. 초기 데이터 · 직원 계정 생성
3. 프로젝트 구조 정리 (Vite)
4. 저장 방식 교체: 로그인 → 게시판 → 전자결재 → 업무관리 → 공사관리 → 메일·일정 → 급여
5. Edge Functions (급여 잠금 해제 · 관리자 작업)
6. Vercel 배포

> ⚠️ 비공개(Private) 저장소. 직원 정보 · 직인 · 서명 이미지가 포함되어 있으므로 공개로 바꾸지 말 것.
